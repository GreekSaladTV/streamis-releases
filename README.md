# Streamis

Приложение для стримера: оверлеи в OBS, алерты донатов, общий чат со всех площадок, заказ музыки,
ИИ-бот в чате. Windows, установка без прав администратора.

**Скачать: [последний установщик](../../releases/latest)** — файл `Streamis-Setup-X.Y.Z.exe`.

Ниже — установка и первые настройки. Всё, что нужно, — скачать установщик и ввести свои доступы
к площадкам. Ничего чужого в приложении нет: база событий, токены, медиа и логи заводятся у тебя
с нуля. Исходный код — в приватном репозитории, здесь только сборки.

## 1. Установка

1. Скачай установщик по ссылке выше (файл вида `Streamis-Setup-X.Y.Z.exe`).
2. Windows покажет синее окно **«Защитник SmartScreen предотвратил запуск»** — это потому, что
   установщик не подписан платным сертификатом, а не потому, что с ним что-то не так.
   Жми **«Подробнее» → «Выполнить в любом случае»**.
3. Установка идёт в твою пользовательскую папку, права администратора не нужны.

**Обновления приходят сами.** Приложение проверяет тот же публичный адрес, ставит новую версию и
предлагает перезапуск. Делать ничего не нужно.

## 2. Где лежат твои данные

Всё своё, локально, на твоём компьютере:

```
%APPDATA%\streamis\
  streamis.db      — история донатов и событий (SQLite)
  secrets.json     — токены площадок (шифруются средствами Windows)
  media\           — картинки и звуки алертов
  logs\            — логи приложения
  backups\         — автоматические копии базы (каждые 6 часов, хранятся последние 10)
```

Никуда наружу это не уходит. Отчёты об ошибках в этой сборке **не отправляются никому** — получатель
не задан, даже если включить галочку в настройках. Всё для разбора есть в локальном логе:
**Настройки → Открыть папку логов**.

## 3. Что ввести при первом запуске

При первом запуске на вкладке **«Источники»** появится панель «С чего начать» — она проведёт
по тем же шагам, что описаны здесь, и закроется, как только хотя бы одна площадка заработает.

Вкладка **«Источники»** — подключи то, чем пользуешься. Наводи на **?** возле каждого поля: там
написано, что это и где брать.

| Площадка | Что нужно |
|---|---|
| Twitch | кнопка «Авторизоваться» — вход в браузере, токен впишется сам |
| YouTube | кнопка «Авторизоваться» — вход через Google (см. ниже, если не пустит) |
| DonationAlerts | кнопка «Авторизоваться» |
| Streamlabs / DonatePay / Donatello / MemeAlerts | свой токен из личного кабинета сервиса |
| Monobank | свой токен из монобанк-API |

### YouTube — заведи своё приложение Google

Это обязательный шаг, и он не только про доступ: **лимит запросов к YouTube считается на приложение,
а не на человека**. Со своим приложением у тебя будет собственный лимит, и ничей чужой чат не будет
отваливаться из-за твоего эфира (и наоборот).

Пять минут, один раз:

1. Открой [console.cloud.google.com](https://console.cloud.google.com/) под той почтой, которой
   входишь в YouTube. Если канал на бренд-аккаунте — под личным аккаунтом, который им управляет.
2. Создай проект (кнопка выбора проекта вверху → «Создать проект», название любое).
3. **APIs & Services → Библиотека** → найди **YouTube Data API v3** → «Включить».
4. **APIs & Services → OAuth consent screen**: тип **External**, заполни название приложения и свою
   почту. **Publishing status переведи в «In production»** («Опубликовать приложение»). Это важно:
   в режиме «Testing» Google аннулирует доступ каждые 7 дней, и придётся входить заново каждую
   неделю. Предупреждение «приложение не проверено» при входе останется — это нормально,
   жмёшь «Дополнительно → Перейти (небезопасно)».
5. **APIs & Services → Credentials** → «Создать учётные данные» → «Идентификатор клиента OAuth» →
   тип **«Десктопное приложение»**. Скопируй **Client ID** и **Client Secret**.
6. В Streamis: вкладка «Источники» → YouTube → «ввести вручную» → вставь оба значения → жми
   «Авторизоваться».

Всё остальное работает так же. Если увидишь ошибку `access_denied` — значит шаг 4 не доделан.

**Про расход лимита.** Чтение чата стоит 1 единицу за запрос раз в 8 секунд — это около 500 единиц
в час, то есть суток лимита хватает примерно на 19-20 часов эфира. А вот **каждое сообщение, которое
бот пишет в YouTube-чат, стоит 50 единиц** — 200 реплик ИИ-бота съедают всю дневную норму. Если
включаешь бота в YouTube, держи шанс ответа низким.

### Twitch — можно на встроенном приложении, можно на своём

По умолчанию Twitch работает сразу, без регистрации: в сборке есть встроенный идентификатор
приложения. Лимит запросов Twitch считает по паре «приложение + аккаунт», так что твои запросы и
чужие в общий счётчик не складываются — мешать друг другу вы не будете.

Своё приложение стоит завести, только если хочешь полной независимости (например, чтобы твои
баллы канала были привязаны к твоему приложению): [dev.twitch.tv/console](https://dev.twitch.tv/console)
→ «Register Your Application» → в **OAuth Redirect URLs** обязательно `http://localhost:7480/callback`
→ категория любая. Полученный Client ID вставь в Streamis в поле Twitch — он перебьёт встроенный.

Вкладка **«ИИ-бот»** (если нужен): туда вводится **твой** ключ от провайдера (OpenRouter, Anthropic,
OpenAI или x.ai). Ключ хранится только у тебя, расход идёт по твоему счёту.

## 4. Сколько осталось лимита YouTube

В карточке источника YouTube во вкладке «Источники» видно, сколько единиц суточного лимита уже
израсходовано из 10 000 и когда он обнулится. Это оценка расхода самим приложением, не официальный
счётчик Google, но расходится с ним мало.

На что уходит: чтение чата — 1 единица раз в 8 секунд, поиск твоей трансляции, пока эфира нет, —
1 единица раз в минуту, а вот **каждое сообщение бота или рекламы в чат — сразу 50**. Если видишь,
что лимит тает быстро, первым делом смотри на ИИ-бота и рекламу в чате: 200 их сообщений — это вся
дневная норма.

Лимит сбрасывается в полночь по тихоокеанскому времени — по Киеву это 10 утра.

## 5. Виджеты в OBS

Вкладка **«Виджеты»** → выбери нужный → кнопка **«Копировать ссылку»** → в OBS добавь источник
**«Браузер»** и вставь адрес. Размер источника — как указано рядом с виджетом.

Оверлей очереди песен, алерты донатов, полоса сбора, топ донатеров, чат, счётчики, таймер марафона —
всё отдельными источниками, включай только нужное.

## 6. Если что-то не работает

1. **Настройки → Открыть папку логов** — открой `streamis.log`, последние строки обычно прямо
   называют причину («нет активной трансляции», «токен протух», «нет права писать в чат»).
2. Цветная точка возле источника во вкладке «Источники»: зелёная — работает, красная — ошибка
   (наведи, там причина), серая — не заполнено, чёрная — выключено.
3. Порт по умолчанию — 7470. Если он занят другим приложением, Streamis возьмёт следующий свободный;
   тогда ссылки виджетов в OBS нужно скопировать заново.
